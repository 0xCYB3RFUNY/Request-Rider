{% load osint_report scanner_report %} {% comment %} Server-rendered Scanner report. The one rule this template exists to hold: no operator-controlled or third-party value is ever marked `|safe`. Django escapes every interpolation by default, and a finding's title, a template name, a matcher output and a response excerpt are all text that came from a target and from a corpus of YAML files the operator did not write. Removing an escape here would be a one-word change that turns a report into a stored-XSS vector, so there is no `|safe` in this file and the `evidence_block` filter exists precisely so the bulky blocks do not tempt anyone into adding one. The numbers come from `scanner_exports.build_scanner_report`, not from counting here. Counting in a template means counting twice, and two counts of the same list eventually disagree. There are exactly three `|safe` marks in this file, on `report_css`, `report_js` and `report_brand`. They are the stylesheet, the behaviour and the masthead — constants written in `scanner_exports.py`, carrying no operator input and no target data. They need it because a script and a style block are raw text: HTML escaping does not apply inside them, so an escaped `'` arrives as the literal six characters `'` and the report does not parse. Every other interpolation is data, and data is escaped. {% endcomment %} {{ report_title }} · RequestRider
