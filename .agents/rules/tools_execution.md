# Project Tool Execution Directive

## Дозвіл на використання програм
- Агент має повний дозвіл оператора на використання будь-яких системних програм, CLI-інструментів, скриптів збірки, тестів та утиліт для реалізації завдань.
- Окремий дозвіл оператора на сам факт запуску кожної команди не потрібен. Агент самостійно виконує команду у рамках погодженого плану робіт.
