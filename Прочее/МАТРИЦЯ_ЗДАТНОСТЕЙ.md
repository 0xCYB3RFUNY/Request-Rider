| інструмент | причина (з виводу, не з припущення) |
|---|---|

| `Ashok` | ModuleNotFoundError: No module named 'Wappalyzer' |
| `dalfox` | потрібен cargo build; cargo у середовищі відсутній |
| `lonkero` | потрібен cargo build; cargo у середовищі відсутній |
| `OpenVulnScan` | ModuleNotFoundError: No module named 'zapv2' |
| `retire.js` | (порожній вивід) |
| `vulncov` | ImportError: attempted relative import with no known parent package |
| `VulnHeist` | ModuleNotFoundError: No module named 'libnmap' |
| `XSSTRON` | Node.js v24.21.0 |

Три з цих причин **не є дефектом клону, а відсутністю середовища**, і це
розділено свідомо:

| причина | скільки | наслідок |
|---|---:|---|
| `cargo` не встановлено | 2 | `dalfox`, `lonkero` — Rust, потрібна збірка |
| пакет є, але потрібна **стара** версія API | 1 | `vulncov` вимагає `langchain.text_splitter`, якого в сучасному langchain немає |
| пакет відсутній у доступному індексі | 3 | `Ashok` (`Wappalyzer`), `OpenVulnScan` (`zapv2`), `VulnHeist` (`libnmap`) |
| потрібна збірка npm | 1 | `retire.js` — TypeScript, `lib/cli.js` не зібрано |
| це не CLI | 1 | `XSSTRON` — розширення браузера, `browser.jsx` |
| потрібні gems Ruby | 1 | `arachni` — потрібен `bundle exec` |
